## Clean-room test (applied to every document)

> *"Could I have written this sentence from public Workday / SAP / SuccessFactors documentation,
> certification material, or community forums — or only from working inside a specific company's tenant?"*

- If **public-knowledge-equivalent**: keep as-is
- If **only from tenant experience**: genericize until public-knowledge-equivalent, or cut
- If **ambiguous**: err toward generic / cut
